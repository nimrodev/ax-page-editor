# Decision Record — AX Page Editor

ADR-style, one entry per settled decision. Compressed into one file rather than one file per
decision: at this project size a folder of 15 stubs is worse than a readable list.

| # | Decision | Rationale | Consequence |
|---|---|---|---|
| 1 | Target **server-rendered pages only**; no JS execution | The pipeline strips scripts, so a JS-heavy SPA yields an empty DOM — nothing to click, nothing to annotate. Editor and "empty page" reveal are mutually exclusive. | Demo on Wikipedia / BBC / Stripe pricing. JS limitation stated in README; Playwright named as upgrade path. Vercel /pricing kept as a cautionary screenshot (1.1 MB HTML, ~7.5 KB text). |
| 2 | Human view keeps the site's **CSS and images**, via injected `<base href>` | The assignment invokes Elementor/Webflow; a bare structural render undercuts the premise. `<base>` is one line vs. rewriting every URL. | Some pages render imperfectly. Hard timebox: 45 min on Tuesday, then ship as-is. |
| 3 | Agent preview defaults to **Markdown**, emitted as an **array of blocks** `{axId, markdown}[]` | Markdown is what LLM crawlers consume and reads better on camera. Blocks (not one string) make Compare-mode highlighting a CSS class instead of character-offset math. | String form produced only for export and token counting. HTML available as a second tab. |
| 4 | Hide is **subtree-inclusive**; child modifications are **shadowed, not deleted**; `context` + `forwardLink` may coexist | A hidden section whose children survive is a bug. Silently deleting a child's annotation loses user work invisibly. | Shadowed mods render greyed in the list as "hidden by parent" and return if the parent is unhidden. |
| 5 | **Honest User-Agent** (`AXEditor/1.0`), no robots.txt enforcement, `AX_USER_AGENT` env override | Spoofing Chrome is a bad look at a company whose business is the crawler/publisher relationship. Full robots support costs ~30 min for little demo value. | Some sites 403 (verified: REI). Override documented; robots enforcement listed under future work. |
| 6 | **URL normalization** as the config key | `/pricing`, `/pricing/`, `?utm_source=x`, `#plans` are one page. | Lowercase scheme+host, strip `www.`, drop fragment, strip `utm_*`/`fbclid`/`gclid`, sort remaining params, drop trailing slash. Original URL retained for display. Non-tracking params (`?product=123`) preserved. |
| 7 | Linear board **timeboxed to 20 min**, after Monday's build block | Plan already exists in BRIEF.md; transcription is mechanical. Value is the visible cut line, not the artifact. | 8 epics, one line per task, no estimates. Epic 7 (proof layer) explicitly labelled cut-candidates. |
| 8 | Hidden elements leave a **strikethrough placeholder** in Compare mode, only while selected | Total vanish is disorienting and indistinguishable from a bug; keeping hidden blocks visible would make the agent pane lie about its output. | Placeholder is selection-scoped, absent in normal Agent view. |
| 9 | Forwarded content is **always a block**, appended after the nearest block-level ancestor | Inlining thousands of words destroys the host sentence. | Markdown blockquote headed by the source URL; anchor text left in place. Dedupe repeated hrefs; cap total forwarded content at ~20k chars per render. |
| 10 | **Diff overlay always on** in Human view | Without it a publisher cannot see their own work on the page — a product hole, not just a skipped bonus. | Dashed red outline = hidden, blue badge = context, green badge = forwarded, plus a legend. ~40 min once ax-ids exist. |
| 11 | A/B panel uses **three fixed questions plus a free-text box** | Fixed prompts make the comparison rigorous: same question, same model, only the representation differs. | Server-side, Sonnet, responses cached by hash(question + payload). Fixtures ship so it runs without an API key. |
| 12 | Ship a dev-only **"simulate page drift"** control | The graded resolver is the strongest engineering story but never fires during a 3-minute recording. | 30 min, Wednesday, only if on schedule. Ranks below Compare mode and the token counter. |
| 13 | **Payload size shown as word count** (zero-dependency); real tokenizer only if time remains | Token counting is not in the assignment's requirements, so it is the last thing built, not a load-bearing feature. Word count is one line, needs no dependency, and carries the same story. | Header shows words; upgrade path is `gpt-tokenizer` (o200k_base) server-side, labelled as a GPT-tokenizer approximation rather than Claude's. Demoted to the final cut-candidate in Epic 7. |
| 14 | Payload figure is a **split, not a net**: noise removed vs. context added | `hide` shrinks the payload but `context` and `forwardLink` grow it; a single "reduction" number displays an *increase* the moment a link is forwarded. | "−4,200 noise · +900 context · 3,100 total". Reframes the claim from shrinking the page to changing its composition — truthful under scrutiny and a stronger point. Ships with whichever unit (words now, tokens later) is in place. |
| 15 | Opening a URL **auto-applies its saved config** | The config is the document; loading the page without it is like opening a file and getting a blank one. | Toast reports counts including stale ones. Explicit dirty-state indicator plus a `beforeunload` guard. |
| 16 | Reviewer runs **`npm install && npm run dev`** and nothing else | The largest way a good submission scores badly is that it did not run. | No Docker, no required env, SQLite created on boot, A/B on committed fixtures. Demo pages committed as HTML fixtures with a live/fixture toggle so evaluation survives being offline or a site redesign. |
| 17 | **Typed failure states rendered inside the preview pane** | Reviewers will paste a URL that fails; what they see then is graded whether or not it was planned. | Four messages — blocked by site (suggest UA override), timed out, unsupported content type, blocked for security. Publisher language, no status codes or stack traces. |
| 18 | Recording **scripted Wednesday, shot Thursday** | Improvising a demo of a tool built hours earlier produces the rambling take. | Seven beats, ~3 min. Rehearse once, record twice, keep the second. |
